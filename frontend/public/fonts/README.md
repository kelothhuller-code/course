Self-hosted fonts (latin subset, variable weight), downloaded from Google Fonts.

- `outfit-latin-var.woff2`: Outfit, weights 500–800. SIL Open Font License 1.1
- `plus-jakarta-sans-latin-var.woff2`: Plus Jakarta Sans, weights 400–700. SIL Open Font License 1.1

They are declared in `src/styles/tokens.css` and preloaded in `index.html`.
